# Microservices with Spring Boot ⚡

This branch contains examples and projects related to **Microservices Architecture** using **Spring Boot**.  
The goal is to demonstrate how large applications can be broken down into smaller, independent services that communicate with each other.

---

## 📘 Topics Covered

- Introduction to Microservices
- Building REST APIs with Spring Boot
- Service Communication  
  - REST Template  
  - Feign Client
- Service Discovery with **Eureka Server**
- API Gateway with **Spring Cloud Gateway**
- Centralized Configuration with **Spring Cloud Config**
- Inter-Service Communication
- Load Balancing with **Spring Cloud LoadBalancer**
- Resilience & Fault Tolerance with **Resilience4j / Circuit Breaker**
- Distributed Tracing & Monitoring (Zipkin, Sleuth)
- Microservices Security with **JWT**

---

## ⚙️ Prerequisites

- **Java 8+**
- **Spring Boot 2+ / 3+**
- **Maven/Gradle**
- **MySQL/PostgreSQL** (for persistence examples)
- **Eureka Server / Config Server** (if running distributed services)
