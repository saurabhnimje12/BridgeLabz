# Java 8 Features 🌟

This branch contains examples and programs related to **Java 8 features**.  
Java 8 introduced major enhancements to the Java programming language, including functional programming, new APIs, and improvements to existing libraries.

---

## 📘 Topics Covered

- **Lambda Expressions** – Passing behavior as code.
- **Functional Interfaces** – `Predicate`, `Consumer`, `Supplier`, `Function`, and custom interfaces.
- **Streams API** – Processing collections in a functional way.
- **Optional Class** – Avoiding `NullPointerException`.
- **Method References** – Using `::` operator.
- **Default and Static Methods in Interfaces**.
- **Date and Time API (java.time)** – New `LocalDate`, `LocalTime`, `LocalDateTime`, `Period`, `Duration`.
- **Collectors and Reduction** – Grouping, partitioning, summarizing.
- **Parallel Streams** – Leveraging multi-core architecture.
- **Nashorn JavaScript Engine** (removed in later versions).

---

## ⚙️ Prerequisites

- Java JDK 8 or higher installed.
- Any IDE (IntelliJ IDEA, Eclipse, VS Code) or terminal for running programs.
