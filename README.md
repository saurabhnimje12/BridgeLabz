# Java Learning Repository 🚀

This repository contains multiple branches, each dedicated to different Java concepts, frameworks, and problem-solving topics.  
You can switch between branches to explore specific topics.

---

## 📂 Branches & Topics

- **jdbc** → Programs and examples using JDBC (Java Database Connectivity).
- **junit-tdd** → JUnit test cases and Test-Driven Development examples.
- **java8** → Features of Java 8 (Streams, Lambda Expressions, Optional, Functional Interfaces).
- **microservices** → Basics of Microservices architecture with examples.
- **strings** → String manipulation programs and interview questions.
- **arrays** → Array-based problems and solutions.
- **logical-programs** → Logical programming problems and practice exercises.
- **data-structures** → Implementations of Stack, Queue, LinkedList, Tree, Graph, etc.
- **design-principles** → SOLID principles and clean coding practices.
- **design-patterns** → Creational, Structural, and Behavioral design patterns.
- **oops** → Object-Oriented Programming concepts (Inheritance, Polymorphism, Abstraction, Encapsulation).
- **spring** → Examples using Spring Framework.
- **springboot** → Spring Boot applications with REST APIs.
- **exception-handling** → Custom exceptions and best practices in exception handling.

---

## 🔀 How to Switch Branches

To explore a particular topic, switch to its branch:

```bash
git checkout <branch-name>


Example:
git checkout jdbc
