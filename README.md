# Java Practice Repository 🚀

This repository contains multiple **modules/branches** covering different concepts of Java, Data Structures, Design Patterns, Collections, and more.  
Each folder or branch demonstrates a specific set of problems or implementations.

---

## 📂 Modules & Topics

### 🎨 Design Patterns
- **AbstractFactoryDesignPattern** → Implementation of Abstract Factory Pattern.
- **FactoryDesignPattern** → Implementation of Factory Pattern.

### 📊 Data Structures & Algorithms (DSA)
- **BidgeLabz_DSA_ArrayList** → Programs on ArrayList operations.
- **BidgeLabz_DSA_Binary_Search** → Programs implementing Binary Search.
- **BidgeLabz_DSA_Linear_Search** → Programs implementing Linear Search.
- **BidgeLabz_DSA_LinkedList** → Programs on LinkedList operations.

### 🧮 Core Programming
- **BidgeLabz_Logical_Programs** → Logical/Mathematical programs.
- **BidgeLabz_Operators_Programs** → Programs using different operators.
- **BridgeLabz_Array_Programs** → Array-based problems and solutions.
- **BridgeLabz_String_Programs** → String-based problems and solutions.

### ⚙️ Exception Handling
- **BridegeLabz_Exception_Handling** → Programs demonstrating exception handling and custom exceptions.

### 📦 Collections Framework
- **BridgeLabs_Collection_List** → Programs using `List` (ArrayList, LinkedList, Vector).
- **BridgeLabs_Collection_Map** → Programs using `Map` (HashMap, TreeMap, LinkedHashMap).
- **BridgeLabs_Collection_Set** → Programs using `Set` (HashSet, TreeSet, LinkedHashSet).
- **BridgeLabs_Collection_Stack** → Programs using `Stack`.
